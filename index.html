Platform rules

No tool can guarantee zero account restrictions. This app avoids stealth bots and unapproved automation.

Facebook Groups: Meta discontinued the general Groups API. This app cannot auto-discover or auto-post to arbitrary public groups. Save links and publish manually only where allowed.
Instagram: automated publishing requires an eligible Professional account and approved Meta permissions.
TikTok: direct posting requires approved Content Posting API access, creator authorization and an audit for public visibility.
Never enter social passwords, session cookies or 2FA codes here.
